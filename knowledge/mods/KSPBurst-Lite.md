# KSPBurst Plugins

- CKAN id: `KSPBurst-Lite`, version v1.7.4.11, by dkavolis
- Kind: Library. Changes rocket design: No
- Needs: Harmony 2
- Needed by: KSPBurst Compiler
- Links: [Source](https://github.com/KSPModdingLibs/KSPBurst), [Forum or homepage](https://forum.kerbalspaceprogram.com/index.php?/topic/201112-*)

KSPBurst Plugins lets mods that need KSPBurst run; the full KSPBurst Compiler, also installed,
adds the speed-up. It's a library with no gameplay effect.
