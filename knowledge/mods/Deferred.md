# Deferred

- CKAN id: `Deferred`, version 1.3.5.0, by Blackrack
- Kind: Visuals. Changes rocket design: No
- Needs: Shabby
- Needed by: nothing else in this install
- Links: [Source](https://github.com/LGhassen/Deferred), [Forum or homepage](https://www.patreon.com/posts/deferred-106557481)

Deferred switches KSP to deferred rendering, which improves lighting performance with compatible
mods. It needs Shabby and Harmony.

## Deferred: notes

- Fairings fade out with a dither effect instead of turning transparent.
- Known incompatibilities include ProceduralFairings (not installed). B9 Procedural Wings needs
  0.46.0 or later (0.46.1 is installed).
- No gameplay effect.
