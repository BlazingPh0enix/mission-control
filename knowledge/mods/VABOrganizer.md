# VAB Organizer

- CKAN id: `VABOrganizer`, version 1.2.0, by Nertea (Chris Adderley)
- Kind: UI. Changes rocket design: No
- Needs: Module Manager, Harmony 2
- Needed by: nothing else in this install
- Links: [Source](https://github.com/post-kerbin-mining-corporation/VABOrganizer)

VAB Organizer shows size tags on parts in the VAB and splits the parts drawer into subcategories.
Tundra Exploration ships patches for it. It doesn't change part stats.
