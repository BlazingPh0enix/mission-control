# KSPBurst Compiler

- CKAN id: `KSPBurst`, version v1.7.4.11, by Unity
- Kind: Library. Changes rocket design: No
- Needs: KSPBurst Plugins
- Needed by: Parallax Continued
- Links: [Source](https://github.com/KSPModdingLibs/KSPBurst), [Forum or homepage](https://forum.kerbalspaceprogram.com/index.php?/topic/201112-*)

KSPBurst Compiler provides Unity's Burst compiler for better multithreaded performance in mods
that use it (here, Parallax Continued). It's a library with no gameplay effect.
