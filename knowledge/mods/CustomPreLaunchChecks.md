# Custom Pre Launch Checks

- CKAN id: `CustomPreLaunchChecks`, version 1.8.1.1, by GER-Space, al2me6, blowfishpro, Capkirk123, NathanKell, pjf, rsparkyc, SirKeplan, StollD, StonesmileGit, stratochief66, zorg2044
- Kind: Library. Changes rocket design: No
- Needs: nothing else in this install
- Needed by: Kerbal Konstructs
- Links: [Source](https://github.com/KSP-RO/CustomPreLaunchChecks), [Forum or homepage](https://forum.kerbalspaceprogram.com/index.php?/topic/204210-*)

Custom Pre Launch Checks is an API that lets mods add their own checks, which run when you press
Launch in the VAB or SPH. Kerbal Konstructs needs it. It adds no parts.
