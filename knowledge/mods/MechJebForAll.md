# MechJeb and Engineer for all!

- CKAN id: `MechJebForAll`, version 1.3.0.7, by linuxgurugamer
- Kind: Flight tool. Changes rocket design: No
- Needs: Module Manager
- Needed by: nothing else in this install
- Links: [SpaceDock](https://spacedock.info/mod/1854/MechJeb%20and%20Engineer%20For%20All), [Source](https://github.com/linuxgurugamer/MechJebForAll), [Forum or homepage](https://forum.kerbalspaceprogram.com/index.php?/topic/174934-13x-14x-mechjeb-and-engineer-forall/)

MechJeb and Engineer for All uses Module Manager to add a MechJeb computer, Flight Engineer and
Build Engineer to any craft with a probe core or command module, so no extra parts are needed.

## MechJeb and Engineer for All: notes

- Don't add the MechJeb AR202 case or Kerbal Engineer parts to a build; every craft with a pod or
  probe core already has both.
