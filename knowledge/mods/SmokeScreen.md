# SmokeScreen - Extended FX Plugin

- CKAN id: `SmokeScreen`, version 2.8.14.0, by Sarbian
- Kind: Visuals. Changes rocket design: No
- Needs: nothing else in this install
- Needed by: Avalanche Plumes, Tundra Exploration - Stockalike Dragon V2 and Falcon 9
- Links: [Source](https://github.com/sarbian/SmokeScreen), [Forum or homepage](https://forum.kerbalspaceprogram.com/index.php?/topic/64987-*)

SmokeScreen extends KSP's engine particle effects (smoke and exhaust). Tundra Exploration and
Avalanche Plumes need it. It has no gameplay effect.
