# Kopernicus Planetary System Modifier

- CKAN id: `Kopernicus`, version 2:release-1.12.1-251, by BryceSchroeder, Teknoman117, Thomas P., NathanKell, KillAshley, Gravitasi, KCreator, Sigma88, R-T-B, prestja, steamroller
- Kind: Planet system. Changes rocket design: Indirectly
- Needs: KSP Texture Loader, Module Manager, ModularFlightIntegrator, Harmony 2
- Needed by: Parallax Continued
- Links: [Source](https://github.com/Kopernicus/Kopernicus), [Forum or homepage](https://forum.kerbalspaceprogram.com/index.php?/topic/200143-*)

Kopernicus lets mods replace or change the planetary system. In your install it's there because
Parallax Continued needs it; no planet pack is installed, so the stock system is unchanged.

## Kopernicus: notes for the copilot

- The delta-v map holds for the stock system only. If a planet pack or rescale mod is added
  later, the map and the surface gravities in the delta-v engine no longer apply.
- Kopernicus takes over asteroid spawning, and with more than one star it swaps in its own
  solar-panel logic.
