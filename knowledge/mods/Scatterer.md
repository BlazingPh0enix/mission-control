# Scatterer

- CKAN id: `Scatterer`, version 3:v0.0878, by blackrack
- Kind: Visuals. Changes rocket design: No
- Needs: Scatterer Sunflare, Scatterer Default Config
- Needed by: nothing else in this install
- Links: [SpaceDock](https://spacedock.info/mod/141/Scatterer), [Source](https://github.com/LGhassen/Scatterer), [Forum or homepage](http://forum.kerbalspaceprogram.com/index.php?/topic/103963-wip-scatterer-atmospheric-scattering)

Scatterer adds atmospheric scattering shaders: realistic skies, atmospheres seen from orbit and
ocean shaders. It needs the Scatterer Default Config and Scatterer Sunflare packs. It doesn't change
aerodynamics, so ascent figures are unaffected.
