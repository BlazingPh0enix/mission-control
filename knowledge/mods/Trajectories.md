# Trajectories

- CKAN id: `Trajectories`, version v2.4.5.5, by Youen, Kobymaru, PiezPiedPy, linuxgurugamer
- Kind: Flight tool. Changes rocket design: No
- Needs: Module Manager, Toolbar Controller, SpaceTux Library
- Needed by: nothing else in this install
- Links: [SpaceDock](https://spacedock.info/mod/396/Trajectories), [Source](https://github.com/linuxgurugamer/KSPTrajectories), [Forum or homepage](https://forum.kerbalspaceprogram.com/index.php?/topic/162324-131-181)

Trajectories predicts where a craft will come down, accounting for atmospheric drag and lift. It
works with stock aerodynamics.

## Trajectories: notes for the copilot

- Use it for the aerobraked missions in the delta-v map, to check the re-entry or aerocapture
  periapsis before committing.
- Kerbal Reusability Expansion recommends it for aiming booster landings.
