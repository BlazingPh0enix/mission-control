# HUD Replacer

- CKAN id: `HUDReplacer`, version 1.4.2, by UltraJohn, steamroller
- Kind: UI. Changes rocket design: No
- Needs: Harmony 2
- Needed by: ZTheme
- Links: [Source](https://github.com/KSPModStewards/HUDReplacer), [Forum or homepage](https://forum.kerbalspaceprogram.com/index.php?/topic/229134-*)

HUD Replacer swaps the game's HUD and UI textures for a texture pack's (here, ZTheme). It has no
gameplay effect.

## HUD Replacer: Phase 2 note

The screen companion's screenshots show the replaced UI, not the stock one, so describe it to the
vision model when asking about the navball or other instruments.
