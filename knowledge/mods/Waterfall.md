# Waterfall Core

- CKAN id: `Waterfall`, version 0.11.0, by Chris Adderley (Nertea)
- Kind: Visuals. Changes rocket design: No
- Needs: Module Manager
- Needed by: Avalanche Plumes, Stock Waterfall Effects, Waterfall - Restock
- Links: [Source](https://github.com/KSPModStewards/Waterfall), [Forum or homepage](https://forum.kerbalspaceprogram.com/index.php?/topic/196309-wip-waterfall-a-framework-for-continuous-mesh-driven-engine-effects-dec-19/)

Waterfall Core drives mesh-based engine plume effects. On its own it does nothing; Stock
Waterfall Effects, Waterfall - Restock, Avalanche Plumes and Tundra Exploration's patches supply
the plumes. It has no gameplay effect.
