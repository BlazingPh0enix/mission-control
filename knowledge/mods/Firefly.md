# Firefly

- CKAN id: `Firefly`, version 1.0.6, by MirageDev
- Kind: Visuals. Changes rocket design: No
- Needs: Module Manager, FireflyAPI
- Needed by: nothing else in this install
- Links: [SpaceDock](https://spacedock.info/mod/3813/Firefly), [Source](https://github.com/M1rageDev/Firefly), [Forum or homepage](https://forum.kerbalspaceprogram.com/topic/226818-firefly-revamped-atmospheric-effects/)

Firefly replaces the stock re-entry and aerodynamic visual effects with its own. It needs
FireflyAPI and Module Manager. Its documentation describes visual changes only, so re-entry
heating is stock.
