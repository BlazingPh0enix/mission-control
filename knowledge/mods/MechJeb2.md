# MechJeb 2

- CKAN id: `MechJeb2`, version 2.15.4.0, by Sarbian, lamont-granquist, Anatid, r4m0n
- Kind: Flight tool. Changes rocket design: No
- Needs: Module Manager
- Needed by: nothing else in this install
- Links: [Source](https://github.com/MuMech/MechJeb2), [Forum or homepage](http://forum.kerbalspaceprogram.com/index.php?/topic/154834-*)

MechJeb 2 is an autopilot and information mod: ascent guidance, landing guidance, a maneuver
planner, rendezvous and docking autopilots, and delta-v statistics per stage.

## MechJeb 2: notes for the copilot

- Normally a craft needs the AR202 case part; MechJeb and Engineer for All adds MechJeb to every
  probe core and command pod in your install instead.
- In science and career modes, MechJeb's features unlock with specific R&D tech nodes, and some
  need tracking station level 2.
- Its delta-v window is a good cross-check for `evaluate_build`: compare stage by stage before
  trusting a new build.
