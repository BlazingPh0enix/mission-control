# KSP Community Part Modules

- CKAN id: `KSPCommunityPartModules`, version v0.5.1, by sofiebrink
- Kind: Part framework. Changes rocket design: Indirectly
- Needs: Harmony 2
- Needed by: Tundra Exploration - Stockalike Dragon V2 and Falcon 9
- Links: [SpaceDock](https://spacedock.info/mod/3730/KSP%20Community%20Part%20Modules), [Source](https://github.com/KSPModdingLibs/KSPCommunityPartModules)

KSP Community Part Modules is a shared set of part modules used by several mods; on its own it does
nothing. Tundra Exploration needs it.

## KSP Community Part Modules: modules

- `ModuleCenterFollowTransform`: moves a part's centre of mass, lift or pressure with a transform.
- `ModuleAutoCutDrogue`: cuts drogue chutes automatically when the main chutes deploy.
- `ModuleDepthMask`: hollow insets (engine nozzles, gear bays) that don't clip into other parts.
- `ModuleNameTag`: a name tag on a part, shared by kOS (`part:TAG`) and kRPC (`Part.Tag`). The
  Phase 2 companion can read these tags through kRPC.
