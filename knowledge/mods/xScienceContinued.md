# [x] Science! Continued

- CKAN id: `xScienceContinued`, version 6.0.3.1, by Z-Key Aerospace, Brodrick, Flupster, linuxgurugamer
- Kind: Planning tool. Changes rocket design: Indirectly
- Needs: ClickThrough Blocker, Toolbar Controller, SpaceTux Library
- Needed by: nothing else in this install
- Links: [SpaceDock](https://spacedock.info/mod/3100/[X]%20Science!%20Continued), [Source](https://github.com/linuxgurugamer/KSP-X-Science), [Forum or homepage](https://forum.kerbalspaceprogram.com/index.php?/topic/199287-*)

[x] Science! Continued is a science checklist: it tracks which experiments are done, recovered or
still held on vessels and kerbals, per body, situation and biome.

## [x] Science! Continued: notes for the copilot

- When advising on tech-tree unlocks, ask the player what [x] Science! shows as still available
  nearby (Mun and Minmus biomes are the usual early science sources).
