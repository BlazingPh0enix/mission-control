# ModularFlightIntegrator

- CKAN id: `ModularFlightIntegrator`, version 1.2.10.0, by Sarbian
- Kind: Library. Changes rocket design: No
- Needs: nothing else in this install
- Needed by: Kopernicus Planetary System Modifier
- Links: [Source](https://github.com/sarbian/ModularFlightIntegrator), [Forum or homepage](https://forum.kerbalspaceprogram.com/index.php?/topic/106369-*)

calculations) without conflicting. Kopernicus needs it. It's a library.
